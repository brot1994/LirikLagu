# Lirik Lagu

App Android: dengarkan lagu yang sedang diputar, kenali judulnya, lalu tampilkan liriknya berjalan seperti subtitle.

- Pengenalan lagu: [AudD](https://audd.io) (isi token di ⚙ Pengaturan)
- Lirik tersinkron: [LRCLIB](https://lrclib.net) (gratis)
- Subtitle melayang di atas app lain, bisa digeser naik-turun
- Otomatis mengenali lagu berikutnya saat lagu selesai
- Koreksi waktu ±0,5 detik, atau ketuk baris berikutnya untuk lompat ke sana

APK dibuat otomatis oleh GitHub Actions — lihat tab **Releases**.
